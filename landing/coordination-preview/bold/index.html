Paste into your coding agent
Set up Flopwire for this coding agent using https://github.com/flopwire/flopwire.
Read the current README and SECURITY.md first. Explain what transcripts it collects and who can read shared transcripts.
Check for an existing installation before installing. If a source build is needed, check the repository’s Go requirement and install the web dependencies with pnpm --dir web install --frozen-lockfile, then run make build.
Start local indexing with flopwire agent run --no-sync. Use the built binary’s absolute path if it is not on PATH. Keep the device agent running using the documented method for this OS.
Register flopwire mcp as a stdio MCP server in this coding tool. For Claude Code, use claude mcp add flopwire -- /absolute/path/to/flopwire mcp. For Codex, add an mcp_servers.flopwire entry with the binary’s absolute path as command and ["mcp"] as args. Preserve existing settings.
Verify the connection by listing sessions and reading a returned session address. Use Flopwire to search earlier work when context is missing; read the source passage before relying on a result.
Keep this setup local. Ask before enrolling a device or uploading transcripts to a team server. If I want team access, follow the documented invite, claim, enrollment, and path-rule steps, then configure flopwire mcp --server.
Tell me what you installed and how to stop it. Live agent messaging is planned; do not configure or promise messaging tools that are not in this release.
