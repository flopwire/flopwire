Search like code. Read the evidence.

Two capabilities worth showing in detail: tools an agent can navigate and source records it can inspect.

A search-to-source workflow

Use ranked keyword search to discover earlier work, literal or regex grep to investigate exact text, and bounded reads to reopen the source. Session outlines help navigate long conversations.

search   discover relevant work
grep     match exact text or regex
read     inspect the source and context

CLI and MCP share query semantics. Results expose scope and partial-result limits; a server failure does not silently become a local search.

AgentsView also offers exact/regex search, coverage reporting, and revision-bound reads. These are concrete interface strengths, not a measured claim that Flopwire agents need fewer calls.

Captured records, beyond a summary

Reopen available prompts, responses, commands, and tool results. Stable source addresses and raw-record reads let an agent check what the captured evidence actually says.

That matters when a command’s output or the difference between a proposal and a decision changes the answer.

Original evidence is not exclusive to Flopwire: AgentsView retains raw sources, Entire uses transcript checkpoints, SpecStory exposes session Markdown, and Langfuse retains instrumented traces. Capture rules, redaction, supported formats, and budgets bound what is available. Comparative fidelity has not been measured.

Sources, versions, and limits

Flopwire claims reference source 2cd1455, October 16, 2026. The competitor review began October 13; search interfaces and evidence representations were rechecked October 16. The comparison is qualitative. No speed, token-saving, or fidelity ranking is claimed.

  • Flopwire: search, source reads, and commit evidence
  • AgentsView: agent-facing search and evidence reads
  • Agent Mail: messages, coordination, and reservations
  • Entire v0.11.4: Git-linked sessions and checkpoints
  • SpecStory: session search and resume
  • Langfuse: trace search

Commit lookup returns captured evidence, not proof of sole authorship. Squash merges need the original PR commit IDs. Messaging requires a routable recipient; availability and replies are separate from delivery receipts.
