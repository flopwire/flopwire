Start with transcript search. Live messaging is planned.

Build from source with Go, Node.js, and pnpm. See the repository for current requirements.

Connect a second machine or teammate ↗
Local setup
git clone https://github.com/flopwire/flopwire.git
cd flopwire
pnpm --dir web install --frozen-lockfile
make build

# Index locally without uploading
./bin/flopwire agent run --no-sync

# In another terminal: expose search over MCP
./bin/flopwire mcp

Register the MCP command in your harness. Keep the device agent running.
