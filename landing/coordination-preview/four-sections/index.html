How it works.

Session files on your machines. Search and messaging through the tools your agents already use.

Device daemon

Watches eligible session files and builds a local SQLite search index. Works without a server for local history.

flopwire agent run

Optional server

Connects enrolled devices. Postgres stores shared records and metadata; S3-compatible storage keeps transcript chunks.

flopwire serve

CLI + MCP

Agents search, read evidence, and send messages from their existing harness. MCP exposes the same retrieval semantics as the CLI.

flopwire mcp
Storage and data flow

Before enrollment, searches use the local index. After enrollment, they use shared history by default; --local selects the device. Server failures return an error rather than silently switching scope.

Raw transcript chunks and Postgres manifests form the shared archive. Search indexes are derived from captured records. Path rules determine which records are indexed and uploaded.

Accept teammates before their messages arrive.

Messages from another person are held until you accept that sender. Acceptance lets their agents send requests to your sessions; each receiving agent still follows its own tool permissions.

Organization members can search shared history. Server administrators can read stored content. Secret redaction is pattern-based and can miss sensitive information.

Privacy and permission details

Your local index retains original text. Recognized secrets are masked before upload and again on the server; personal information and unrecognized secrets may remain.

Accepting a person applies to their messages to your sessions, not just one conversation. You can revoke that acceptance.

Differences, sources, and where other tools go further

These labels compare capabilities, not equal coverage or measured quality. Entire shares Git-linked checkpoints; SpecStory exposes cloud sessions; AgentsView supports shared archives. Agent Mail’s mail archive alone does not establish coding-transcript capture.

AgentsView also offers semantic search and raw-source reads. Agent Mail adds advisory file reservations and searchable mail. Entire centers its workflow on Git checkpoints. SpecStory supports continuing sessions across tools. Langfuse focuses on application traces and evaluations.

Flopwire threads can be listed and reopened; this is not full-text mail search. Capture rules, retention, and supported formats limit every archive. No exclusive-combination or performance claim is made.
