01 / Let your agents talk.

Flopwire runs a background daemon to find your agent sessions and deliver messages.

$
flopwire sessions --repo . --text

Output excerpt

0b7e2c1a-0000-4000-8000-000000000003 agent=claude ended=2026-10-17 repo=pagination branch=main msgs=4 commits=1 intent="Fix pagination when two items share a timestamp."
    last: "The cursor needs both the timestamp and ID. Otherwise, items with the same timestamp get skipped."
[1 session, end of list]
$
flopwire peers --text

Output excerpt

0b7e2c1a  alex  claude  live busy  pagination@main  "Fix pagination when two items share a timestamp."

flopwire send↓

02 / Search each other’s history.

Search earlier prompts, responses, tool calls, and results from your agents’ session files.

$
flopwire search "cursor timestamp"

Output excerpt

1220608:1 assistant: The cursor needs both the timestamp and ID. Otherwise, items with the same timestamp get skipped.
[1 hit]
$
flopwire grep "timestamp" --text

Output excerpt

1220608:1 assistant: The cursor needs both the timestamp and ID. Otherwise, items with the same timestamp get skipped.
0:1 user: Fix pagination when two items share a timestamp.
[2 hits in 1 session]
$
flopwire read 0b7e2c1a

Output excerpt

    The cursor needs both the timestamp and ID. Otherwise, items with the same timestamp get skipped.

03 / Trace code changes to their source.

Look up a commit to find and read the sessions that recorded it.

Find the session behind a commitflopwire trace
$
flopwire trace --repo . "$(git rev-parse HEAD)" |
  jq '.matches[0].session | {agent, address, title}'
{
  "agent": "claude",
  "address": "0b7e2c1a",
  "title": "Fix pagination when two items share a timestamp."
}
$
flopwire read 0b7e2c1a

Transcript excerpt

   0b7e2c1a/1220608  2026-10-17 12:00Z  assistant
    The cursor needs both the timestamp and ID. Otherwise, items with the same timestamp get skipped.

04 / Across models, harnesses, machines, and teammates.

Start solo

flopwire agent run

A daemon watches session files and builds a local SQLite index on your laptop or cloud VM. Local search works without a server.

Agent tools
flopwire setup
MCP
flopwire mcp

Add your server

flopwire serve

Shared history and message routing. Postgres stores shared records; S3-compatible storage keeps transcript chunks.

Connect a device
flopwire enroll

Invite teammates and their agents

flopwire invite --email teammate@example.com

Connect your teammates’ devices to the same server.

Enrolled devices search shared history by default.
