Installation & self-hosting
Apache-2.0 / self-hosted

Build from source

The commands below use flopwire, the current package name, and the retrieval development branch.

Requires Git, Go 1.26.6+, Node.js, and pnpm. Team sync also needs the server deployment.

Full setup instructions
Local setup
git clone --branch integ/full https://github.com/flopwire/flopwire.git
cd flopwire
pnpm --dir web install --frozen-lockfile
make build

# Index locally without uploading
./bin/flopwire agent run --no-sync

# In another terminal: expose search over MCP
./bin/flopwire mcp

Register the MCP command in your harness. Keep the device agent running.

Connect a second machine or teammate +

Deploy the team server, create an invitation, and enroll each device. Run the device agent with sync enabled, and use flopwire mcp --server for team retrieval.

How agents use Flopwire

Agents find related work through repositories, commits, and sessions. They send a heads-up to the relevant agent and retrieve more context only when needed.
